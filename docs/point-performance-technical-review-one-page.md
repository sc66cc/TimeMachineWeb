# TimeMachineWeb 大规模深时点渲染性能测试评审摘要

**评审结论（2026-07-27）**：Web 端采用“服务端/离线分配 Plate ID + 紧凑二进制 + Worker + GPU 四元数旋转”的路线可行。10k、100k、275k、真实 PBDB 275,291、1M、5M 六档数据均已成功加载和绘制；在 Apple M2 Max（38 核 GPU、96 GB）硬件浏览器人工验收中，时间轴交互表现符合本阶段预期。该结果足以支持继续建设 TimeMachineWeb，但尚不能直接证明全量替代 Unity：本轮没有保存可复核的硬件 FPS/p95 trace，也没有完成同机、同场景的 Unity A/B 测试。

## 一、测试范围与关键结果

| 指标 | 本轮结果 | 技术含义 |
|---|---:|---|
| 数据规模 | 10k / 100k / 275k / 真实 275,291 / 1M / 5M | 六档均通过加载、GPU 上传和绘制功能回归 |
| PBDB 数据质量 | 原始 275,347；接受 275,291；拒绝 56 | 36 条缺失必需值，20 条年龄区间无效 |
| Plate ID 分配 | 275,272 条成功；首次 2.764 s，约 99,600 点/s | 在服务端/离线阶段完成，并按 XLSX、GPML、ROT 哈希缓存；不占用页面逐帧预算 |
| 极限测试口径 | 全部点在 0–1100 Ma 永久有效 | 任意时刻均提交全量点，避免因年龄过滤“虚减”负载；19 个未分配点仅在性能夹具中挂到锚定板块 0 |
| 数据与显存基线 | 20 B/点；1M 约 19.1 MiB；5M 约 95.4 MiB | 不创建数百万个 JS 对象；5M 仍为一个顶点缓冲、一个 draw call |
| 时间轴计算 | CPU 只更新活动 Plate ID 四元数；GPU 逐顶点旋转 | CPU 更新量由点数 **N** 降为板块数 **P**；点数增加主要转化为 GPU O(N) 工作 |
| 正确性与回归 | 最终记录 50 项自动化测试通过；生产构建通过 | 覆盖 ROT、四元数、重建树、GPML、WGP1、永久有效期等；六档无头回归无 WebGL/页面错误 |

瓶颈判断已经明确：时间轴拖动不再受 JavaScript 逐点旋转和坐标回写限制；5M 之后的主要风险转为 GPU 顶点/片元负载、过绘制、浏览器内存与资源释放。5M 释放慢主要是等待在途绘制、驱动异步回收约 95.4 MiB GPU buffer，以及浏览器随后回收约 100 MiB CPU ArrayBuffer，而不是四元数计算本身。

## 二、与当前 Unity 方案的对比

| 维度 | TimeMachineWeb / Cesium 优势 | 相对 Unity 的不足 |
|---|---|---|
| 大规模点更新 | 单一紧凑 buffer；shader 按 Plate ID 查四元数。当前 Unity 点链路会建立 `TablePointRuntimeRecord`/`PlatePoint` 对象，并在时间更新时遍历点、重新提交几何；Web 路线扩展性更好 | 浏览器 GPU/显存指标不完整，驱动和 GC 回收时机不可完全控制 |
| 交付与数据分发 | URL 即开即用，便于 CDN、对象存储、HTTP 瓦片、分享和跨平台协作 | 浏览器、GPU、系统组合差异大，最低设备能力必须单独验收 |
| 工程与功能成熟度 | 更适合在线数据、项目协作和前后端分层；组件可直接嵌入其他 Web 业务 | 当前 Web 仍是渲染内核/实验台；Unity 已有较完整的项目、图层、上传和交互能力 |
| 调试与资源治理 | Web Worker、列式数据和网络 trace 易于定位传输/主线程问题 | Unity Profiler、Memory Profiler 和原生 GPU 工具更成熟；Web 大 buffer 卸载需要两阶段释放和池化 |

## 三、评审建议

建议批准 Web 方案进入产品化阶段，但采用“逐模块替代、Unity 保持可用”的路径：先替换大规模点与板块重建内核，再接入图层、项目和服务端能力。下一性能关卡必须补齐三项：① 在 `DESKTOP-BASE` 和 `DESKTOP-MID` 固定设备保存 FPS、p95 帧时、输入到渲染延迟、Long Task、内存原始结果；② 用相同 PBDB、相机、样式和时间脚本完成 Unity/Web 同机 A/B；③ 为 1M–5M 增加空间瓦片、LOD、地平线/视锥剔除及“两阶段释放”。因此本轮结论应表述为：**Web 大规模点重建架构已验证可行，具备替代当前 Unity 点渲染路径的潜力；完整客户端替代仍需产品能力迁移和量化 A/B 验收。**
